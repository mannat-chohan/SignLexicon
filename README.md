#SignLexicon

##AI-powered Sign Language Recognition System using Computer Vision and Deep Learning

###Overview

SignLexicon is a deep learning-based sign language recognition system developed during my Industrial Training at Solitaire Infosys Pvt. Ltd.

The application recognizes hand signs using a Convolutional Neural Network (CNN). It supports both image upload and real-time webcam recognition through an interactive desktop interface.


##Features

- Real-time sign language recognition using webcam
- Image upload prediction
- CNN-based deep learning model
- User-friendly desktop GUI
- Confidence score for predictions
- Fast and accurate classification


##Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Pillow (PIL)
- Tkinter
