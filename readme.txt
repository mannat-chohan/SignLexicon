PROJECT TITLE:
SignLexicon - Sign Language Recognition System using Computer Vision and Deep Learning

DEVELOPED BY:
Mannatdeep Kaur Chohan

ORGANIZATION:
Solitaire Infosys Pvt. Ltd.

DESCRIPTION:
This project recognizes static American Sign Language (ASL) alphabets using a Convolutional Neural Network (CNN). The application supports both image upload and real-time webcam prediction through a graphical user interface developed using Python Tkinter.

TECHNOLOGIES USED:
- Python
- TensorFlow
- OpenCV
- NumPy
- Pillow
- Tkinter

HOW TO RUN:
1. Open app_v1.py.
2. Install the required Python libraries.
3. Ensure the trained model file is present in the same folder (if applicable).
4. Run the application.
